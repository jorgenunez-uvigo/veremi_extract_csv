For the veremi_full dataset, put all the zips except the MixAll_0024 in a root folder, copy the extract_zips.sh into the folder and run it.
Then run "python3 parse_traces.py <root_folder> <output.csv>"

For the veremi_mixall dataset, extract the MixAll_0024 in a root folder, copy the extract_zips.sh into the folder and run it.
Then run "python3 parse_traces_mixall.py <root_folder> <output.csv>"
